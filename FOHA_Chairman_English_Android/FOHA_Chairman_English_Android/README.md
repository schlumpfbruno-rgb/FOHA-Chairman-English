# FOHA Chairman English — Android APK

This is a real Android application wrapping the offline FOHA Chairman English dictionary. It does not use Base44 or Jotform and does not require an internet connection after installation.

## Build with Android Studio
Open this folder in Android Studio and choose **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
The debug APK will be under `app/build/outputs/apk/debug/`.

## Build automatically for free with GitHub Actions
1. Upload this folder to a GitHub repository.
2. Open the **Actions** tab.
3. Run **Build Android APK**.
4. Download the generated APK from the workflow run's **Artifacts** section.
5. Transfer the APK to the Android phone and install it.
